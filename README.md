# Balachandra Dasari — Resume

Personal resume website for **Balachandra Dasari**, Senior Technical Associate (Android Developer) at Atyati Technologies, Bengaluru.

**Live site:** https://chandra1234456.github.io/Resume/

## About

A single-page, static resume built with plain HTML and CSS (no build step or dependencies).

- Responsive layout for desktop and mobile
- Automatic light/dark mode
- Print-friendly styling: use the **Download / Print PDF** button to save as PDF

## Structure

```
.
├── index.html   # the entire site (content + styles)
└── README.md
```

## Run locally

Open `index.html` in any browser, or serve it:

```bash
python -m http.server 8000
```

then visit http://localhost:8000.

## Deployment

Hosted with GitHub Pages from the `main` branch (root). Pushing changes to `main` updates the site automatically.
